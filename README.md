# relating

Relating: one boundary system where actions project to CLI, HTTP, OpenAPI, MCP, and docs from one registry, and each carrier is one JSON-Schema literal interpreted by FromSchema and the runtime validator.

## Operation execution carriers

The operation constructor imports the module-closure supplier's execution-only
port. Its default Node carrier still executes admitted source bytes. Bundlers
selecting the `workerd` condition use the supplier's explicit
`programme-carrier-unavailable` refusal for JSNode programmes, without importing
Node's source-capture loader into the Worker. Host-function and SEN operations
remain available. This does not grant a Worker Node execution capabilities or
route programmes to another actor automatically.

`npm test` covers Node execution after origin mutation and workerd-conditioned
host, SEN and unavailable-JSNode behavior. Downstream bundles must select the
correct export condition and receive the updated dependency closure; a source
change here does not replace previously installed versions.
