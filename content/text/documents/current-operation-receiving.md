# Current operation and language receiving

## Required boundary
Relating's existing operation declaration owns invocation of its selected host,
SEN or addressed JavaScript body. SchemaContract owns domain/codomain admission;
Code Engine owns SEN; Module Closure owns admitted JavaScript execution. Relating
preserves synchronous return when the selected body is synchronous, asynchronous
completion otherwise, all three invocation arguments, and handler-result evidence
and artifacts while admitting its value. Workerd still receives host/SEN and
refuses only the unavailable Node program carrier. This is not the different
Node JSON CLI operation protocol.

- Replace obsolete Data/Code Section SEN imports with Code Engine's actual
  exports, preserving underlying mathematical operations.
- Remove the dependency on Code Section's deleted typed-operation helper. Perform
  this declared operation's precondition/body/postcondition directly in its
  existing operationWithEvidence implementation using original schema assertions.
  No deleted typed-operation module, compatibility alias or alternate executor is
  reinstated. Invocation closes over admitted declaration fields, not mutable
  caller specification properties.
- Follow SignGraph's explicit diagram/schema and SVG relocation into Content.
  Original move: SignGraph commit 7dd36043702b922e573d1402569f2f8512a0ffce.

  Both articulation carrier exports now use the actual articulationCellSchema;
  the meme carrier remains the predicate cellSchema.

  identities in an explicit schemaFromGraph rather than demand a removed global
  schema-registration collision policy. Two different bodies under the same
  explicit graph identity still refuse. No Schema or SignCell implementation was
  changed to make this consumer pass.
- Ship all original and new native test programs through the package's existing
  files/receivingTests convention. The full source test command remains unchanged.
